# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone taking part in its issues, discussions, and pull requests is expected to uphold it.

In short: be welcoming and considerate, critique ideas rather than people, and accept that maintainers have the final say on what fits the project. Harassment, personal attacks, and discriminatory language are not tolerated.

## Reporting

If someone's behavior breaks this code of conduct, raise it with the maintainer, [@AdamAkhlaq](https://github.com/AdamAkhlaq), by mentioning them on the issue, pull request, or discussion where it happened. For harassment or abuse you don't want to raise in public, use GitHub's [report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) feature on the comment or user; those reports go to GitHub's staff, who enforce GitHub's own terms. This project has no private reporting channel of its own yet.

Maintainers may edit or remove contributions that break this code of conduct, and may block people from the project, temporarily or permanently, following the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
