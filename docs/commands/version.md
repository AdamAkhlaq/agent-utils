# `version`

Print the binary's version as a bare, script-friendly value. `agent-utils --version` and `agent-utils -version` do the same.

## Usage

```sh
agent-utils version
```

## Examples

```sh
agent-utils version     # e.g. v1.3.0
agent-utils --version   # same output
```
